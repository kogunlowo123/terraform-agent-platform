# aws/rds

PostgreSQL on RDS with production defaults:

- Multi-AZ on by default, never publicly accessible, TLS forced (`rds.force_ssl`).
- Storage, Performance Insights and the credentials secret all KMS-encrypted
  (dedicated rotated key created when none is supplied).
- Enhanced monitoring (60s), CloudWatch log exports, IAM DB auth.
- Master password generated by Terraform and stored **only** in Secrets Manager.
- `deletion_protection = true` and final snapshot enforced.

## Usage

```hcl
module "postgres" {
  source = "../../terraform/aws/rds"

  identifier = "${module.naming.prefix}-pg"
  vpc_id     = module.vpc.vpc_id
  subnet_ids = module.vpc.intra_subnet_ids

  allowed_security_group_ids = [module.eks.cluster_security_group_id]

  engine_version = "16.4"
  instance_class = "db.m6i.large"

  parameters = {
    max_connections = { value = "500" }
  }

  tags = module.tags.tags
}
```

## Inputs

| Name | Type | Default | Description |
|---|---|---|---|
| `identifier` | `string` | — | Instance identifier. |
| `engine_version` | `string` | `"16.4"` | Postgres version; family derived. |
| `instance_class` | `string` | `"db.m6i.large"` | Instance class. |
| `allocated_storage` / `max_allocated_storage` | `number` | `100` / `500` | gp3 storage + autoscale ceiling. |
| `db_name` / `username` | `string` | `tap` / `tap_admin` | Initial DB and master user. |
| `multi_az` | `bool` | `true` | Standby in second AZ. |
| `vpc_id`, `subnet_ids` | — | — | Placement (use intra subnets). |
| `allowed_security_group_ids` / `allowed_cidr_blocks` | `list` | `[]` | Ingress on 5432. |
| `kms_key_arn` | `string` | `null` | CMK; null creates one. |
| `parameters` | `map(object)` | `{}` | Extra parameter group entries. |
| `backup_retention_period` | `number` | `14` | 7–35 days. |
| `monitoring_interval` | `number` | `60` | Enhanced monitoring seconds. |
| `performance_insights_enabled` | `bool` | `true` | PI with KMS. |
| `deletion_protection` | `bool` | `true` | Keep true outside sandboxes. |
| `apply_immediately` | `bool` | `false` | Apply outside maintenance window. |
| `tags` | `map(string)` | `{}` | Tags. |

## Outputs

| Name | Description |
|---|---|
| `instance_id`, `instance_arn`, `endpoint`, `address`, `port`, `db_name` | Connection details. |
| `security_group_id` | Instance SG. |
| `secret_arn` | Secrets Manager credentials. |
| `kms_key_arn` | Encryption key. |
| `parameter_group_name` | Parameter group. |
